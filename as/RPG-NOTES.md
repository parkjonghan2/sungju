# 게임 디자인 노트

- 장르: 2D 횡시점 배경 + 탑다운 이동 기반의 B급 호러 코미디 RPG.
- 스토리: 이성주와 친구들이 여관을 찾는다 → 예상 밖의 손님들을 만나 친구들이 도망친다 → 이성주만 방에 남는다 → 복도에서 듣는 정체불명의 소리 → 극적인 귀환 → "너네는 왜 안 했니?" → 추격 → 멀티 엔딩.
- 조작: WASD/방향키 이동, E/스페이스 상호작용, 모바일 터치.
- 인터랙션: 입구, 간판, 성주/친구 NPC, 201~204호, 자판기, 출구, 203호 타이밍 미니게임, 마지막 추격전.
- 엔딩: 도망자, 잡힘, 기억삭제, 우정, 전설, 자판기, 청취 퍼펙트.
- 사진: 타이틀(합성 게임 포스터) + 성주 얼굴 초상화 + 203호 손님 얼굴 초상화. 모든 파일은 `dist/assets`에 있습니다.
- 기술 스택: 순수 HTML/CSS/Canvas/JS. 오프라인 실행 가능, Vercel static site 배포. 외부 CDN 없음.

## 1.1 배경음악
- 제공 MP4에서 추출한 MP3 148초 루프. 15% 기본 음량, 시작 클릭 후 재생.
- 게임 시작/재시작 이후 재생 상태를 유지하고 효과음 버튼과 별개로 BGM On/Off 및 슬라이더 조절 가능.

## 1.2 모바일 지원
- 휴대폰 세로/가로 레이아웃. 가로 방향에서는 게임 옆에 방향 패드와 E 조사 버튼을 배치합니다.
- 터치로 목표 위치를 지정해 자동 이동하거나, 사물을 눌러 자동 접근·조사할 수 있습니다. 방향 버튼을 꾹 누르면 터치 이동을 중단하고 수동 이동합니다.
- 모든 미니게임, 선택지, 결과 화면에 터치 버튼을 제공합니다.
