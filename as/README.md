# 이성주: 203호의 전설

친구들끼리 즐기는 **실행 가능한 2D 웹 픽셀 공포 코미디 RPG**입니다. HTML/CSS/JavaScript, 이미지 세 장, 추출한 MP3 배경음악으로 동작하며 서버, 외부 라이브러리, 빌드가 필요 없습니다.

## 바로 플레이

`dist/index.html` 파일을 크롬 또는 엣지에서 더블클릭하면 게임을 시작할 수 있습니다. ZIP 배포는 `dist` 폴더 **전체**를 보존해야 이미지/효과음/조작이 정상 작동합니다.

- 키보드: 방향키 또는 WASD 이동, E 또는 스페이스 조사 및 대사 진행.
- 스마트폰(세로/가로): 게임 화면을 터치하면 그 위치로 자동 이동합니다. 사물이나 문을 터치하면 접근 후 자동 조사합니다. 게임 아래(가로 화면에서는 오른쪽)의 네 방향 버튼을 길게 누르거나 `E 조사 / 대사` 버튼을 눌러서도 조작할 수 있습니다. 모바일 화면 360×640, 390×844, 430×932, 667×375, 844×390에서 점검했습니다.
- 배경음악: 제공된 MP4에서 오디오만 추출한 `dist/assets/bgm.mp3`(2분 28초). 게임 시작 시 기본 15% 음량으로 반복 재생되며, 별도의 BGM ON/OFF 및 볼륨 슬라이더로 조절합니다. 브라우저 자동재생 정책에 따라 게임 시작 버튼을 눌러야 음악이 재생됩니다.
- 효과음은 브라우저 Web Audio로 생성하며, 배경음악과 별도로 켜고 끌 수 있습니다.
- 거리를 돌아다니며 여관에 입장하고, 2층을 탐험하고, 친구들과 대화하고, 203호에서 세 번의 청취 타이밍 미니게임과 도주 액션을 거쳐 여러 엔딩에 도달합니다.
- 엔딩은 공유 가능하며 결과 인증서 PNG를 생성할 수 있습니다.

## Vercel 배포 (GitHub 없이 가장 쉬운 방법)

1. https://vercel.com/new 에서 프로젝트를 만듭니다. GitHub 연동을 사용한다면 먼저 이 ZIP 내용의 `dist` 폴더, `README.md`를 **GitHub 저장소 루트**에 업로드하세요. 폴더 안에 또 ZIP을 넣으면 안 됩니다.
2. `Import Git Repository`에서 저장소를 선택합니다.
3. Framework Preset: `Other`
4. Root Directory: `./`
5. Build Command: **비워두기** (Override 선택 후 공란)
6. Install Command: **비워두기** (Override 선택 후 공란)
7. Output Directory: `dist`
8. Deploy를 누르고 발급된 `https://...vercel.app` 주소를 친구들에게 공유합니다.

## Vercel CLI가 가능한 경우

저장소 루트에서 `vercel deploy --prod` 후 Vercel의 Output Directory를 `dist`로 설정해도 됩니다.

## 구성

```text
seongju203/
├── README.md
└── dist/
    ├── index.html       # 메인 웹페이지
    ├── style.css        # 반응형 게임 UI
    ├── game.js          # 실제 게임 로직 + 캔버스 렌더링 + 미니게임
    └── assets/
        ├── seongju.webp # 제공된 사진 1
        ├── guest.webp   # 제공된 사진 2
        ├── cover.webp   # 게임 타이틀 이미지
        ├── icon.svg
        └── bgm.mp3    # 제공 MP4에서 추출한 배경음악
```

실명과 실제 인물 사진이 등장하는 성인 관련 패러디입니다. 친구 본인과 사진 속 인물의 사진 이용·배포 동의가 있는 경우에만 공개 링크로 공유하세요. 게임은 사건을 사실로 주장하는 기록이 아니라 과장된 허구의 유머 콘텐츠입니다.
